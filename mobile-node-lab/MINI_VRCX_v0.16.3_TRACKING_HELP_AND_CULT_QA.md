# TGC Staff Companion v0.16.3 — Collapsible Shizuku Help + Cult Verification

This is a source implementation and device QA checklist, not a claim of successful in-game or Discord verification testing.

## Tracking setup / Shizuku help
- Previously the lengthy Shizuku explanation occupied most of the top of Tracking setup. It now appears **after linked-device status, Start/Stop tracking, and the player history shortcut**.
- The explanation starts **collapsed**. Tap **ⓘ What is Shizuku? (optional)** to expand it, or **Hide explanation** to collapse it.
- Expanded/collapsed state survives an Activity recreation (e.g. screen rotation). No change was made to Shizuku permissions, privileged log watching, local history, or Relay uploads.
- Shizuku is only used by the Mobile Node to read VRChat Mobile log files. Ordinary account-based Companion features remain usable without it.

## Gamer Music 2 / Cult verification
- **Verification is started in Discord**, in the already-existing Gamer Music 2 flow, exactly as with Gamer Music 3.
- A VRChat private invite generated by that process can contain a `CULT-XXXX-XXXX` code. The Companion reads only the signed-in personal VRChat account's recent invite data and, where accessible, the **invited instance custom name**.
- An optional selector in the native **Verification code** screen lets staff switch between **Gamer Music 3** (existing `TGC-XXXX-XXXX` flow, unchanged) and **Gamer Music 2 · Cult** (new `CULT-XXXX-XXXX` recognition).
- Each flow also has a separate shortcut from the Companion homepage and account settings.
- The floating Companion's **Tools → Verification** section provides both code readers and **Copy** within the overlay, without launching a separate Activity.
- The existing Discord verification prompt remains the destination for the code: users manually paste into Discord. The Companion never creates a code, automatically sends messages, submits verification to Discord, or asks for Discord credentials.
- Cult code expiry and its dedicated verification world UUID have **not** been supplied; neither is assumed. The reader does not invent an expiry, and only scans recent invites or invitation-associated VRChat instance metadata.
- The Cult reader bounds private-instance metadata lookups to avoid sending large numbers of requests and never alters invite notifications.

## Real-device tests (not yet verified)
1. Upgrade from v0.16.2 using the permanently signed v0.16.3 APK. Confirm personal VRChat sign-in, Node link, stored joins/leaves, Friend Log, and overlay settings persist.
2. Tracking → Tracking setup should display **Device linked / tracking controls** before the one-line **What is Shizuku?** help button. Tap to expand, tap again to hide, and rotate the screen.
3. With Shizuku disabled, use account tools normally. Confirm log-reading Start/Stop still requires the same Shizuku authorization as before.
4. From Gamer Music 3's existing Discord verification, receive a regular TGC private invite and confirm old code extraction, copy behavior, and ten-minute expiry are unchanged.
5. From Gamer Music 2's Discord verification, receive a Cult private invite, choose **Cult**, and verify the displayed code starts `CULT-`, has two four-character groups, and matches the **actual** instance custom name.
6. While VRChat Mobile is foreground, open floating tools → Tools → Verification → Cult. Verify scanning, copying and internal navigation work without switching to the full Companion.
7. After copying, bring Discord to the foreground and paste into **the verification prompt originally started there**. Confirm the app has not independently submitted a code.
8. Switch between TGC and Cult during an in-flight scan; results from the previous mode must never appear under the new tab.
9. Disable personal VRChat login or cause an invite API error: only a useful error should appear, with no fabricated code.
10. Check the published updater feed says v0.16.3 (versionCode 30), signer is the same as v0.16.2, and install is in-place.

## Limitations
- The code reader is a display/copy assistant, not a Discord bot or verification initiator.
- Cult's exact invite payload shape remains to be validated against a real invite. If the code cannot be retrieved from VRChat notification fields or the invited instance's accessible custom display name, the app reports that limitation.
- Shizuku's Android capabilities do not imply Quest tracking support. Quest remains planned research.
